# 🏠 California Housing — Análise Exploratória de Dados

Projeto de **Análise Exploratória de Dados (EDA)** utilizando o dataset California Housing e ferramentas de Python.

## Objetivo

Explorar os dados, identificar padrões, tratar valores faltantes e analisar relações entre as variáveis para preparar os dados para uma futura etapa de Machine Learning.

## Tecnologias

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Análises realizadas

* Inspeção geral dos dados
* Tratamento de dados faltantes
* Normalização e padronização
* Análise de distribuições
* Identificação de possíveis outliers
* Matriz de correlação
* Scatter Plot
* Pairplot

## Principais resultados

A variável `MedInc` apresentou a maior correlação positiva com `MedHouseVal`, indicando uma relação relevante entre renda média e valor médio dos imóveis.

Também foram analisadas distribuições, possíveis outliers e relações entre diferentes características do conjunto de dados.
